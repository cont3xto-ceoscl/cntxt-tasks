# CNTXT® Task & Checklist Engine v1.0

Gestor inteligente y jerárquico de proyectos, tareas y checklists con metodología de Matriz de Eisenhower y visualización en Calendario Dinámico Colombiano para el ecosistema **CNTXT® Casa de Diseño**.

## 🚀 Despliegue en EasyPanel (Hostinger VPS)
- **Proyecto EasyPanel:** `cntxt_admin`
- **Servicio:** `tasks` (o `cntxt_tasks`)
- **Tipo de Servicio:** App (Dockerfile / Nginx Alpine)
- **Puerto:** `80`

## 🛠️ Tecnologías
- HTML5 Semántico + Vanilla CSS3 (Glassmorphism & Identidad CNTXT)
- JavaScript Moderno (Motor reactivo sin frameworks pesados)
- Algoritmo de Días Festivos Colombianos (Ley Emiliani + Pascua)
- Conexión JWT y fallback de sincronización
- Nginx Alpine para serving ultra-rápido (<50ms)
